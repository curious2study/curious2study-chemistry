# Chemistry Course - Curious2Study

## Course Overview

This chemistry course covers general chemistry from foundational concepts through nuclear chemistry. It is built for high school and lower-division undergraduate students, with a focus on clear explanations and practical study strategies.

## Course Materials

Each chapter includes:
- **Video Lectures:** Explanations of core concepts with visual demonstrations
- **Study Guides:** Chapter summaries and key terms

## How to Use This Course

1. **Start with Chapter 1** to build a foundation in chemical principles
2. **Watch the video lectures** for each section
3. **Read the study guides** to reinforce key ideas
4. **Focus on understanding** the reasoning behind concepts, not just memorizing formulas and definitions

## Learning Approach

This course emphasizes:
- Building a solid conceptual foundation
- Developing problem-solving skills for stoichiometry, equilibrium, and thermodynamics
- Connecting chemistry to real-world applications
- Practicing study habits that support long-term retention

## Prerequisites

- Basic algebra
- Familiarity with scientific notation
- Basic understanding of physical quantities and units (helpful, not required)
